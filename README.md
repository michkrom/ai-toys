# ai-toys
Collection of AI/ML toys and plays.

- [torch - a PyTorch playground](torch/README.md) — tiny, self-contained ML
  experiments (morse encoder/decoder, parity bit) behind one CLI
  (`./cli.py morse-encode|morse-decode|parity-learn|morse-translate`), with a shared torch init and
  optional GPU/seed/thread control.
- [pong - a classic TUI Pong game with AI](pong/README.md) — terminal Pong with
  human vs computer play and self-learning agents (Deep Q-Network, algorithmic,
  perfect) behind `pong.py`, plus headless Q-learning training.
